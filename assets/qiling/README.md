# 诗琚的参考音

诗琚的本地声音是儿童女孩。CosyVoice 3 0.5B 没有云端预置音色，只能零样本克隆一段参考录音。

`voice-prompt-girl-child.wav` 是占位：大约 0.25 秒静音，不是任何人的声音。`voice-prompt-girl-child.txt` 的内容是 `STUB`。本机服务启动时会拒绝占位和成年示例稿，健康检查起不来，识局就改用系统语音。

请换成你有权使用的录音，不要把真实儿童声音提交进这个仓库。更合适的位置是应用数据目录，见仓库 `README.md` 的「本地儿童女孩音色」。

- 大约 3–10 秒，单人，没有背景音乐，普通 PCM WAV。
- txt 写成录音里的原句，UTF-8，删掉 `STUB`。
- 不要用 CosyVoice 官方示例「希望你以后能够做的比我还好呦。」那句配的是成年女声。
